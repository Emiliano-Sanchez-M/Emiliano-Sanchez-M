Soy desarrollador independiente especializado en **Java**, **SQL** y **diseño de bases de datos**. Me gusta construir software partiendo del análisis del negocio, aplicando principios de arquitectura limpia y documentación técnica para desarrollar soluciones escalables y mantenibles.

Disfruto creando soluciones web y herramientas de escritorio que combinan una arquitectura limpia con una funcionalidad práctica.  

Además del desarrollo backend, disfruto crear aplicaciones web y de escritorio, así como compartir conocimiento mediante la enseñanza de robótica educativa, Arduino y ESP32.

Siempre estoy aprendiendo nuevas tecnologías y buscando mejorar la calidad del software que desarrollo.
